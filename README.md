# Rhythmbox-Album-Shuffle
This plugin adds an option for Continuous Album Shuffle to Rhythmbox. 

# Features
- Adds a Shuffle Albums button next to the shuffle button to initiate the album shuffle playback.
- Album shuffle can also be started by selecting Tools → Start / Reshuffle Albums.
- Each time album shuffle is started or restarted, the album order is randomized.
- When pressing the album shuffle button a second time, the playlist generated by the plugin will be <b>replaced. If you prefer to keep that playlist in addition to the newly created playlist, you must rename the playlist before reshuffling.</b>
- Playback begins at the first track of a randomly selected album.
- Each album plays from beginning to end, in the correct disc and track order, before moving on to another randomly selected album (regardless of how the tracks are displayed in Rhythmbox's music library).
- Albums are not repeated until all eligible albums have been played, at which point the sequence is reshuffled.
- The plugin respects the currently displayed library filters. For example, if you select a particular genre, only tracks matching that genre are included in the shuffle.
- The currently playing song is automatically highlighted and scrolled into view in the song list, provided it is included in the current filtered view.
- The plugin preserves the current library view and filters while playing.

# Shuffling Methodology
Album Shuffle groups tracks into albums primarily by the Album tag. It uses the Album Artist tag to distinguish albums that share the same title, as is common with names such as <i>Greatest Hits</i>. If Album Artist is not present, all tracks with the same Album value are treated as a single album, regardless of their individual Artist tags or folder locations.

# Installation

For a **user-level installation**, copy the plugin folder into:

`~/.local/share/rhythmbox/plugins/`

For a **system-wide installation**, the location depends on your distribution:

- **Arch Linux:** `/usr/lib/rhythmbox/plugins/`
- **Debian/Ubuntu/Mint (x86_64):** `/usr/lib/x86_64-linux-gnu/rhythmbox/plugins/`
- **Debian/Ubuntu/Mint (ARM64):** `/usr/lib/aarch64-linux-gnu/rhythmbox/plugins/`

For **Flatpak**, use:

`~/.var/app/org.gnome.Rhythmbox3/data/rhythmbox/plugins/`

Restart Rhythmbox, open **Preferences → Plugins**, and enable the plugin.

## Please Note
  The plugin is python-based. The issues regarding the breaking of the python-based Rhythmbox plugins was well known, and they were broken in the past for a significant amount of time. Those upstream issues appear to have been rectified now. However, future changes of  Rhythmbox or its dependencies could cause changes that affect this plugin, particularly if those changes break python-loader. Hopefully this will not happen, but if it does, this plugin could break.
